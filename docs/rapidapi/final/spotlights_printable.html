Context / Extended description (do not paste in RapidAPI — for PDF context only)
TSFA exposes three production-ready forecasting models behind a single REST endpoint:

• ARIMA (AutoARIMA via statsforecast) — runs locally on CPU. Best for short series (<200 observations), interpretable output, and fast turnaround (<300ms). 1 credit/call.

• Chronos-T5-Small (Amazon Foundation Model, GPU via Modal.com) — zero-shot, works on any domain and any frequency without training. 1 credit/call.

• LSTM (Custom PyTorch, GPU via Modal.com) — for long series (>500 obs) with strong seasonal patterns. 2 credits/call.

Pass "model": "auto" to let the API select the best model automatically. If the GPU backend is unavailable, the API silently falls back to ARIMA.

Credit cost: arima = 1, chronos = 1, lstm = 2, ensemble = 5

Fallback: Automatic ARIMA fallback if GPU (Modal.com) is unreachable

Coming (Phase 2): TiDE model for multivariate forecasting with covariates

Context / Quick Start Code (do not paste in RapidAPI)
import requests

url = "https://api.eymdey-network.com/v1/forecast/univariate"
headers = {"X-RapidAPI-Key": "YOUR_KEY", "Content-Type": "application/json"}
payload = {
    "series": [120, 132, 128, 145, 139, 152, 148, 160, 155, 168, 163, 175],
    "horizon": 7,
    "frequency": "D",
    "model": "auto",
}
resp = requests.post(url, json=payload, headers=headers)
data = resp.json()
print(data["forecast"]["mean"]) # [176.3, 179.1, ...]
print(data["forecast"]["lower_95"]) # 95% lower bound

No SDK required: Standard HTTP — works with requests, curl, fetch, HTTPClient

No training: Send raw data, receive forecasts. Zero model management
