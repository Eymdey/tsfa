How it works

No training pipeline. No infrastructure. No ML background required.

1

Code example

Forecast in 10 lines of Python

The complete call. No SDK. Just requests.

Python 
import requests

url = "https://tsfa.p.rapidapi.com/v1/forecast/univariate"
headers = {
    "X-RapidAPI-Key": "YOUR_RAPIDAPI_KEY",
    "Content-Type": "application/json",
}
payload = {
    "series": [120, 132, 128, 145, 139, 152, 148, 160, 155, 168, 163, 175],
    "horizon": 7,
    "frequency": "D",
    "model": "auto",
}
resp = requests.post(url, json=payload, headers=headers)
data = resp.json()
print(data["forecast"]["mean"])      # [176.3, 179.1, ...]
print(data["forecast"]["lower_95"])  # 95% lower bound
print(data["model_used"])             # "arima" or "chronos"
